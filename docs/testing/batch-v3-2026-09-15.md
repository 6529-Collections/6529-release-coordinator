## Upgrade problem found and fixed

The first command stopped before it obtained a usable journal lock or created a
trial PR. The live journal contained one exact earlier `sandbox-batch-v2`
record saved before the required sandbox workflow blob changed. The code knew
the later v2 shape but rejected the earlier code-owned shape as untrusted, so
every new run would stop while reading valid old state.

The fix adds only that exact earlier policy shape to the trusted policy list.
An altered field still fails. The old elapsed deadline remains part of the
historical fingerprint but no longer stops work. Direct readback confirmed the
journal was unlocked after the failed start. A focused 44-test set passed before
the live retry.
