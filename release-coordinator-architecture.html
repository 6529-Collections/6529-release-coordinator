Ask for a release

What happens

The developer tells the existing agent what should go to staging or production. There is no new form or manual JSON work. 


          


          

            Current and next
            

              Today, the CLI creates and validates the request. Every run is saved locally. Only a
              valid request is added to the local outbox.
            

            

              The frontend release skill uses this local preflight. The backend integration is next.
              The CLI does not send anything yet.
            

            

              Next, the same CLI will gain a submit command. It will start one workflow
              in this Release Coordinator repository, wait for it, and return success or failure.
              The first workflow will only validate and log the request. It will not call an inbox.
            

            

              Source: packages/release-request/. Product repositories install only
              @6529-collections/release-request. They do not install the future
              Coordinator application.
